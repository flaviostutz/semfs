# Customer Escalation Path

HelioHome support should route customer issues in this order.

## Level 1

- App pairing help
- Password reset
- Basic thermostat schedule questions

## Level 2

- Gateway offline troubleshooting
- Smart lock pairing failures
- Firmware rollback checks

## Level 3

- Repeated leak sensor false positives
- Door access failures during an active incident
- Safety complaints involving electrical heat or smoke concerns

Any Level 3 case requires an operations manager note in the incident log.
