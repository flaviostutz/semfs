# Field Visit Preparation

Use this checklist before sending a technician to a home with thermostat, lock, or hub issues.

## Pre-Visit Questions

1. Which devices are failing right now?
2. Is the gateway powered and showing a green, blue, or amber LED?
3. Has the home router changed in the last seven days?
4. Are there large electronics, cabinets, or mirrors near the hub location?

## Items To Bring

- Backup gateway hub
- Smart lock battery tray
- Thermostat wall plate
- Spare sensor batteries

Technicians should arrive with the latest install app and the property access note already loaded.
