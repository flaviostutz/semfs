# App Pairing Troubleshooting

When a resident cannot pair the mobile app with installed devices, support should follow this order.

1. Confirm the resident is using the invite link tied to the correct home.
2. Check whether the gateway hub is online.
3. Verify Bluetooth and local network permissions on the phone.
4. Ask whether the thermostat or smart lock was recently reset.
5. Retry pairing after refreshing the resident profile token.

If app pairing still fails, create a technician visit when the home also shows an amber hub LED or missing lock events.
