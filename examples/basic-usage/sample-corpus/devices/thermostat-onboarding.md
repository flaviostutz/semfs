# Thermostat Onboarding Guide

Use this guide when installing the HelioHome smart thermostat in a new customer home.

## Prerequisites

- The gateway hub must already be online.
- The installer app must show the correct property profile.
- HVAC power should be turned off before opening the wall plate.

## Steps

1. Scan the thermostat QR code.
2. Match each wire label before disconnecting the old device.
3. Mount the new thermostat and restore HVAC power.
4. Wait for the app to confirm cloud registration.
5. Run the heating and cooling self-test.

If the thermostat cannot find the gateway within two minutes, move the hub closer and retry pairing.
